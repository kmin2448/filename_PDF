# PDF Auto-Renamer

업로드한 PDF 청구서 내부의 텍스트를 추출해 지정된 규칙에 맞게 파일명을 자동 변경하고,
비목별 폴더로 분류해주는 Windows 데스크톱 GUI 프로그램입니다.

## 기능

- PDF 다중 업로드 (드래그 앤 드롭 / 파일 탐색기)
- 1페이지에서 이체일자, 적요, 비목, 금회청구액 추출
- 3페이지 이후에서 거래처명(성명) 추출 (여러 건이면 `대표거래처 외 N건`)
- `(YYMMDD) 적요_거래처명(성명)_(금회청구액).pdf` 형식으로 파일명 자동 생성
- `[저장 루트 폴더]/[번호. 비목]/` 경로에 자동 분류 저장 (원본 파일은 그대로 유지)
- 저장 루트 폴더는 프로그램에서 변경 가능하며, 기본값은 `바탕화면/청구서정리`

자세한 사양은 [prd.md](prd.md)를 참고하세요.

## 비목 폴더 규칙

PDF에서 추출한 비목명은 아래 규칙에 따라 번호가 붙은 폴더로 자동 생성됩니다.

| PDF의 비목 | 생성되는 폴더명 |
| --- | --- |
| 인건비 | `01. 인건비` |
| 장학금 | `02. 장학금` |
| 교육 연구프로그램개발 운영비 | `03. 교육연구프로그램개발운영비` |
| 교육 연구환경개선비 | `04. 교육연구환경개선비` |
| 실험 실습장비및기자재 구입 운영비 | `05. 실험실습장비및기자재구입운영비` |
| 지역연계 협업지원비 | `06. 지역연계협업지원비` |
| 기업지원 협력활동비 | `07. 기업지원협력활동비` |
| 성과활용 확산지원비 | `08. 성과활용확산지원비` |
| 기타운영경비 / 그 밖의 사업운영경비 | `09. 그 밖의사업운영경비` |
| 간접비 | `10. 간접비` |

- PDF 표에서 비목이 줄바꿈·띄어쓰기가 제각각으로 추출되는 경우(`교육 연구프로그램개발\n운영비`)와
  `>선택` 같은 꼬리표가 붙는 경우도 같은 폴더로 매핑됩니다.
- 위 표에 없는 비목은 번호 없이 추출된 이름 그대로 폴더가 만들어집니다.
- 매핑 규칙은 [src/core/file_manager.py](src/core/file_manager.py)의 `CATEGORY_FOLDER_MAP`에서 수정할 수 있습니다.

## 실행 파일(exe) 받는 방법

`dist/` 폴더는 저장소에 포함되지 않고, GitHub Actions가 Windows에서 자동으로 빌드합니다.

- **최신 개발 버전**: 저장소 상단 **Actions** 탭 → `Build Windows EXE` 최신 실행 선택 →
  하단 **Artifacts**의 `PDF_Auto-Renamer-windows` 다운로드 (zip 안에 exe가 들어 있습니다. 로그인 필요)
- **정식 배포 버전**: 버전 태그를 올리면 **Releases** 페이지에 exe가 자동 첨부됩니다.

  ```bash
  git tag v1.0.0
  git push origin v1.0.0
  ```

## 기술 스택

- Python 3.x
- PyQt6 (GUI)
- pdfplumber (PDF 파싱)
- PyInstaller (실행 파일 패키징)

## 설치 및 실행

```bash
pip install -r requirements.txt
python main.py
```

## 실행 파일 직접 빌드

```bash
pyinstaller --clean --noconfirm PDF_Auto-Renamer.spec
```

빌드 결과물은 `dist/PDF_Auto-Renamer.exe`로 생성됩니다.

## 주의

100% 로컬 환경에서만 동작하며, 외부 서버로 데이터를 전송하지 않습니다.
실제 청구서 PDF와 파싱 결과 파일은 개인정보 및 계좌정보를 포함하므로
`.gitignore`에 의해 저장소에 커밋되지 않습니다.
